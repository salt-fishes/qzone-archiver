重构说明

本版本是我在原作者 ShunCai 的 QZoneExport 基础上进行的个人重构版。

为什么重构

  • Manifest V2 已被 Chrome 淘汰：原版基于 MV2（manifest_version: 2, version 2.0）开发，Chrome 自 2024 年起已逐步停用 MV2，原扩展在新版浏览器中无法加载。
  • CSP 限制收紧：原版 CSP 含 'unsafe-eval' 与 jsdelivr、staticfile、thunderurl 等多个远程 CDN，MV3 明确禁止 eval/new Function 与扩展页面远程脚本。
  • 远程依赖治理：原版扩展页面与 14 个导出模板（albums/blogs/boards/diaries 等）大量依赖 cdn.staticfile.org、cdn.jsdelivr.net 与 www.lvshuncai.com/custom/js/clicklove.min.js，网络波动时页面直接错乱、模板渲染失败。
  • 原作者已归档：原作者于 2024 年将项目归档停止维护，部分接口与 QQ 空间最新数据结构脱节且无法修复。

动了哪些模块

  • manifest.json：MV2 → MV3；background.scripts → background.service_worker；page_action → action；CSP 收紧为仅 self；移除所有远程 CDN 域名白名单。
  • background.js：持久态从全局变量迁移到 chrome.storage.session；安装/更新跳转从 lvshuncai.com 改为内置 html/docs.html；chrome.extension.getURL 全部改为 chrome.runtime.getURL；网络请求用 fetch + AbortController 替代 XMLHttpRequest。
  • 模板系统：原版使用 vendor/template/template.js 运行时编译（依赖 new Function，被 MV3 CSP 拦截），重构为 tools/precompile-templates.js 预编译到 src/js/templates-compiled.js，规避 eval。
  • 模板资源：14 个 src/templates/*.html 全部移除 cdn.staticfile.org、cdn.jsdelivr.net、clicklove.min.js 等远程引用，断网亦可查看。
  • 扩展页面：options/about/tools/indicator 的第三方库（bootstrap/jquery/lodash 等）全部从 vendor/ 本地加载；隐私政策、常见问题、使用说明、更新日志跳转全部内置为本地 HTML。
  • 新增 SPA 前端：新增 Vue 3 + Vite + Pinia 的单页应用（src/spa），打包为单 IIFE 文件，兼容 file:// 协议直接打开；支持说说、日志、相册、视频、留言、好友、收藏、分享、访客九大模块的现代化浏览（搜索、按年份分组、详情弹窗、虚拟滚动）。
  • 新增已删除说说恢复：基于 feeds2_html_pav_all 通知接口与 emotion_cgi_msgdetail_v6 详情接口实现，独立存放于 messages-deleted.js，不污染主索引。
  • 作者署名：src/js/modules/*.js 与 src/export/js/statistics.js 中的 @author https://lvshuncai.com 统一替换为 @author https://github.com/ShunCai/。

优势与不足

优势

  • 兼容最新 Chrome MV3 规范，可正常加载与上架
  • 扩展页面与导出 HTML 全部资源本地化，断网亦可正常查看
  • 模板预编译，启动更快，符合 CSP
  • 新增 SPA 前端，备份数据浏览体验现代化（搜索、分组、虚拟滚动）
  • 新增已删除说说恢复功能
  • 文档内置，安装即查看，无需联网
  • 网络请求统一为 fetch，符合 Service Worker 规范

不足

  • 仅个人维护，更新频率无法保证
  • SPA 前端目前仅支持浏览，暂不支持编辑/导出
  • 已删除说说恢复依赖通知接口，仅能恢复有互动记录的内容，私密说说无法恢复
  • 部分历史边缘场景未充分验证（如老版本增量数据兼容）
  • 未在 Edge / 360 等其它 Chromium 浏览器上充分测试
  • 原版导出 HTML 的 BootstrapTable 表格视图暂未在 SPA 中等价复刻

落叶随风，青春，稍纵即逝，QQ空间，一个承载了很多人的青春的地方。

或许，是遗憾，毕竟，谁的青春没留遗憾呢，《曾经沧海无限感慨，唯愿往事随风》。我是往事随风。你好，我是轻舞飞扬。

或许，是害怕，曾经的青春变得不可控，毕竟，新浪博客相册、网易相册、腾讯微博等相继停运，无不意味着，互联网产品都有着自己的生命周期。

于是，萌生了备份QQ空间的念头，也在互联网上找到一些工具与脚本，要么操作复杂、要么备份类型单一，于是乎，简单易用全类型备份的QQ空间导出助手诞生了。

功能清单

  1. 支持备份QQ空间文字说说、图文说说、语音说说、长说说，以及评论、点赞、最近访问
  2. 支持备份QQ空间文字日志、图文日志、模板日志，以及评论、点赞、最近访问
  3. 支持备份QQ空间文字日记、图文日记，以及评论、点赞、最近访问
  4. 支持备份QQ空间相册/相片，以及相册/相片的评论、相册/相片的点赞、相册的最近访问
  5. 支持备份QQ空间视频，以及评论、点赞、最近访问
  6. 支持备份QQ空间留言寄语与留言、以及留言回复
  7. 支持备份QQ好友、含好友成立时间、单向好友检测、空间访问权限检测、特别关心的好友等
  8. 支持备份QQ空间分享内容，以及评论、点赞、最近访问
  9. 支持备份QQ空间收藏内容
  10. 支持备份QQ空间访客，仅支持备份谁访问了我，非全部备份，备份内容的多少，看是不是黄钻

快速开始

  1. 阅读隐私政策，并安装与配置助手。
  2. 登录并访问需要备份的QQ空间，在备份的QQ空间页面点击浏览器扩展栏的助手图标开始备份。
  3. 助手开始采集数据，采集时长视空间数据量而定，请耐心等待采集完成，主号建议睡前备份。
  4. 数据采集完成后，采集页面点击打包下载按钮打包文案内容(即说说、日志等文字内容)到压缩包。
  5. 等待压缩包下载完成，压缩包存放的是文案内容，不包含多媒体文件，解压后得到QQ空间备份_QQ号命名的文件夹。
  6. 等待多媒体文件下载完成，多媒体文件将会下载到助手配置的下载工具本身所设置的文件夹中，生成QQ空间备份_QQ号命名的文件夹。
  7. 合并第5步与第6步中的两个QQ空间备份_QQ号命名的文件夹中的内容，即剪切或复制其中一个所有内容到另外一个即可。
  8. 打开合并后的QQ空间备份_QQ号命名的文件夹中的index文件查看备份内容即可。
  9. 如需要，可再次把合并后的QQ空间备份_QQ号命名的文件夹复制、剪切到其它地方可进行再次备份，避免因磁盘损坏等导致备份丢失或损坏。

  3. 本助手基于QQ空间官方网站备份个人空间数据，与QQ空间不存在任何联系。
  4. 使用本助手即同意助手收集QQ空间网站的Cookie信息，仅用于获取QQ空间数据，不传输任何数据到后台服务器，仅保存到浏览器客户端。
