# 发布冒烟清单（P6.2 §8.2）

> 每阶段合入门禁 · 发布前人工签字执行 · 配套自动化：CI 四门禁（typecheck / lint / vitest / build）
> 用例 4 为 **P0-1 回归项**，任何涉及下载调度 / 任务状态的改动必测。
> 引擎运行日志现落盘于 `%APPDATA%/qzone-archiver-desktop/logs/main.log`（P6.1），排查时优先查看。

## 环境

- [ ] 安装版（NSIS）与 portable 版各跑一轮
- [ ] Windows 10 / 11 各一台；首次安装（无残留 userData）与升级安装各一轮

## 用例

| # | 用例 | 步骤 | 通过标准 | 结果 |
|---|---|---|---|---|
| 1 | 扫码登录 | 启动应用 → 顶栏「扫码登录」→ 手机 QQ 授权 | 引擎窗自动最小化；顶栏登录态自动刷新（昵称/头像/QQ 号） | ☐ |
| 2 | 全模块备份 | 勾选全部模块 → 选择保存位置 → 开始备份 | 逐模块完成日志 + 成功页数据（条目数/文件数/体积）与产物目录一致 | ☐ |
| 3 | 暂停/恢复 | 备份进行中 → 暂停 → 等待 → 恢复 | 引擎采集挂起 + 下载中断（.part 保留）；恢复后断点续传，无重复文件 | ☐ |
| 4 | **取消→再备份（P0 回归）** | 备份中取消 → 立即重新开始 | 新任务下载列表出现 running 条目且文件落盘；重复 3 次循环无残留 | ☐ |
| 5 | 增量备份 | 首次完成后，模块增量改为「上次」→ 再次备份 | 仅采集上次之后新增内容，耗时显著缩短，产物完整 | ☐ |
| 6 | 产物浏览 | 打开目标目录 → 双击 index.html；应用内历史 → 打开 | SPA 可浏览说说/相册/视频；viewer 窗口正常，外链被拦截不弹新窗 | ☐ |
| 7 | zip 打包 | 历史卡片 →「打包 zip」 | 产物 zip 生成 + 进度显示 + 资源管理器定位 | ☐ |
| 8 | 全量重备 | 删除产物目录 → 重启应用 → 再次备份 | 正常全量重备（增量元数据双读回退 engine-storage 生效） | ☐ |
| 9 | 日志可观测（P6.1） | 上述任一用例后检查 `logs/main.log` | 引擎日志带级别（info/warn/error）落盘；无 qzone 页面噪音行 | ☐ |
| 10 | **头像渲染（v4.7.5 回归）** | 首页「最近任务」/ 档案列表分组 / 新建任务目标卡片 | 显示真实头像图（<img>，data URL），不是"首字文字头像"；取不到图时才回落首字 | ☐ |
| 11 | **表情渲染（v4.7.5 回归）** | 昵称含 `[em]e327806[/em]` 的账号登录，看首页/顶栏/最近任务/关联档/结果页 | 昵称表情显示为图片，页面上不存在 `[em]e…[/em]` 原始代码 | ☐ |
| 12 | **产物表情完整性（v4.7.5 回归）** | 备份到空目录 → 检查 `Common/images/` → 打开产物 index.html | 内置表情（经典 e1~e320 + 魔法 e327xxx）齐备（含 .gif 别名）；档案里说说的表情显示为图片 | ☐ |
| 13 | **昵称三层兜底（v4.9 §A）** | 冷启动 → 扫码登录 → 引擎注入完成 | ≤10s 内首页问候/顶栏/向导本人卡片三处都显示昵称；断网或引擎未就绪时三处显示 `QQ 号` 且不重复、不空白 | ☐ |
| 14 | **主题跟随系统（v4.9 §D）** | 设置选「跟随系统」→ Windows 切换浅/深色 | 界面 ≤1s 内跟随、无需重启；重启后保持；三态来回切换无残留样式 | ☐ |
| 15 | **退出登录关窗（v4.9 §B）** | 备份界面点「退出登录」 | QQ 空间窗口立即消失；顶栏显示未登录且状态为「未连接 · 点击重试」；备份进行中退出被拒并提示先取消 | ☐ |
| 16 | **关窗状态自刷新（v4.9 §B）** | 手动关掉 QQ 空间窗口 | 1s 内顶栏自动变「未连接/连接失败 · 点击重试」（无需点任何按钮）；点重试重新拉起窗口回到「已连接」 | ☐ |
| 17 | **非好友标签（v4.9 §C）** | 手输一个非好友 QQ 号备份 → 看档案列表/首页最近任务 | 分组标题是「QQ 号」、标签是「他人空间」；向导入口名为「访问空间」；真好友的「好友」标签保留 | ☐ |
| 18 | **打字机与动效降级（v4.9 §H/I）** | 未登录进首页；系统开启「减少动态效果」再进 | 未登录标题逐字打出并循环；开启减少动效后打字机为静态文案、首页背景不流动 | ☐ |
| 19 | **圆角图标（v4.9 §F）** | 看 exe 属性图标 / 任务栏 / 开始菜单 / 窗口标题栏 / 首页 hero | 五处均为圆角矩形且同一图形；16/24/32 小尺寸下圆角仍可见不糊 | ☐ |
| 20 | **便携版 splash（v4.9 R2）** | 运行 portable.exe | 自解压期间显示品牌 splash 画面，不再"点了没反应" | ☐ |
| 21 | **日志双轨（v4.9 §K）** | 冷启动 → 跑一次备份 → 打开 `%APPDATA%/qzone-archiver-desktop/logs/` | `main.log` 有会话开始行（版本/pid/userData）；出现 `backup-<taskId>.log` 且能独立看出"跑到哪个模块、何时停"；设置 → 高级 →「打开日志目录」可直达 | ☐ |
